# PLANET MERGE v0.2

HTML・CSS・JavaScriptだけで動く宇宙の惑星パズルです。
有料サービス、APIキー、外部画像、追加ライブラリは不要です。

## MacBook Airで起動する

1. Finderを開きます。
2. 「PLANET-MERGE」フォルダを開きます。
3. `index.html`をダブルクリックします。
4. Safariなどのブラウザにゲームが表示されます。
5. マウスをゲーム画面内で動かし、点線で発射方向を確認します。
6. クリックして離すと惑星が発射されます。
7. 惑星が固定されたら、次の惑星を発射できます。

ファイルがエディタで開く場合：index.htmlを右クリック →「このアプリケーションで開く」→「Safari」を選びます。
すでにゲームを開いている場合は、ブラウザで再読み込み（Command + R）してください。

## iPhoneで遊ぶ

公開したサイトをSafariで開きます。ゲーム画面を指で押し、動かして照準を合わせ、指を離すと発射します。
指でのゲーム操作中は画面がスクロールしません。画面をスクロールしたいときはゲーム画面の外を操作します。

## v0.2のルール

- 惑星は六角形グリッドへ固定され、左右の壁で反射します。
- 同じ惑星が隣接すると、上側（天井に近い側）のマスで進化します。下側の惑星は消えます。
- 同じ高さなら左側を残します。同じ惑星が複数隣接する場合も上側、次に左側の順で相手を選びます。
- 連鎖は進化後に残ったマスから判定します。
- 水星 → 金星 → 地球 → 火星 → 木星 → 土星 → 天王星 → 海王星 → 冥王星。
- 冥王星どうしは両方消えます。
- 発射候補は最初は水星・金星・地球です。合体で初めて作った惑星が候補に追加されます。
- 画面の「発射できる惑星」に候補を表示します。未解放の進化アイコンは薄く表示されます。
- 抽選の重みは、水星を1として、金星1/2、地球1/4、火星1/8…と半分ずつになります。解放済みの候補だけで抽選します。上位惑星は出にくくなっています。
- NEXTに表示した惑星はそのまま次に発射します。アンロックした惑星は、それ以降のNEXTの抽選から登場する可能性があります。
- 赤い破線が危険ラインです。固定された惑星の判定範囲の下端がラインに達するとGAME OVERになります。飛行中の惑星は判定しません。
- 危険ラインは合体・連鎖の終了後に判定します。合体で上へ移動しラインから離れた場合は続行できます。
- ゲームオーバー中は照準と発射が停止します。「もう一度遊ぶ」で盤面、発射候補、照準、アニメーションなどを最初に戻します。
- 「はじめから」でも同じ初期化ができます。アンロックは保存されず、再開・再読み込みで最初の3種類に戻ります。
- 宇宙船の砲身は照準に合わせて回転します。発射の基準点はv0.1と同じです。

惑星の数字1〜9は進化段階です。見た目の大きさは進化で変わりますが、グリッドと衝突・危険ライン判定の半径は21で統一しています。
得点・効果音・宙に浮いた惑星の落下はありません。天井とのつながりが切れた惑星もマスに残ります。
衝突先の近くに空きマスがない場合、発射した惑星は配置されず案内が表示されます。

## 自分で動作を確認する

1. 開いた画面の上部が「VERSION 0.2」になっていることを確認します。
2. マウスを左右に動かし、点線と宇宙船の砲身が同じ方向に向くことを確認します。
3. 横方向を狙って発射し、壁で反射することを確認します。
4. 同じ惑星を狙い、上側で進化することを確認します。同じ高さなら左側に残ります。
5. 地球どうしを合体させて火星を作り、「発射できる惑星」に火星が加わることを確認します。ランダムなので、すぐに火星がNEXTに出るとは限りません。
6. 異なる惑星を下側に積み、赤い危険ラインに達すると「GAME OVER」と「もう一度遊ぶ」が表示されることを確認します。
7. ゲームオーバー中にマウスを動かしたりクリックしても発射されないことを確認します。
8. 「もう一度遊ぶ」を押し、最初の盤面と3種類の発射候補へ戻ることを確認します。
9. iPhoneでは同じ操作を「指で押す → 動かす → 離す」で確認します。

## 自動テスト

`tests/game.test.cjs`はNode.jsの標準機能だけで動く計算・状態管理のテストです。
Node.jsがすでにある場合は、ターミナルでこのフォルダを開いて次を実行できます。

```sh
node tests/game.test.cjs
```

ゲームを遊ぶためにNode.jsをインストールする必要はありません。
15件のテストで、壁反射、天井・グリッドへの固定、上下・左右の合体位置、位置が移動する連鎖、冥王星までのアンロック、重み付き抽選、冥王星消滅、ゲームオーバー、合体による危険回避、再開時の初期化、マウス・タッチのイベント処理、描画関数の実行を確認しています。
テストは画面を模した環境で実行するため、ブラウザの表示や実機のタッチ操作を保証するものではありません。

## GitHub Pagesで公開

1. GitHubでPublicのリポジトリ（例：planet-merge）を作成します。
2. 「Add file」→「Upload files」で `index.html`、`style.css`、`game.js` をアップロードしてCommitします。
3. 「Settings」→「Pages」で「Deploy from a branch」を選びます。
4. ブランチ `main`、フォルダ `/ (root)` を選んでSaveします。
5. 公開完了後に表示されるURLを開きます。iPhoneでも同じURLで遊べます。

すでに公開している場合は、上記3ファイルを更新してCommitします。公開処理後にブラウザを再読み込みしてください。
この作業ではGitHubへのアップロード・公開は行っていません。

## ファイル一覧

- index.html：ゲーム画面、ゲームオーバー表示、再開ボタン
- style.css：デザイン、画面サイズ対応、未解放惑星とゲームオーバー表示
- game.js：ゲーム処理、宇宙船描画、合体、危険ライン、アンロック
- README.md：起動手順、ルール、確認方法、公開手順
- tests/game.test.cjs：依存ライブラリ不要の自動テスト
